# #357 Bump `@aws-sdk/client-s3` to 3.1178.0 (Dependabot)

The Dependabot PR title says "Bump @smithy/config-resolver ... to removed", but the real change is in `backend/package.json`: `@aws-sdk/client-s3` 3.700.0 -> 3.1178.0 (same major). The old `@smithy/config-resolver` 3.x was only a transitive dependency of the old SDK; it leaves the lockfile because newer SDK releases no longer pull it in, which is what the security group update wanted.

| File                   | Change                                                            |
| ---------------------- | ----------------------------------------------------------------- |
| `backend/package.json` | `@aws-sdk/client-s3` pinned to 3.1178.0                           |
| `package-lock.json`    | Regenerated by Dependabot; `npm ci` now reports 0 vulnerabilities |

Impact on #300 photo storage: `backend/src/storage-s3.ts` imports only `S3Client`, `PutObjectCommand`, `GetObjectCommand` and `DeleteObjectCommand`, which are unchanged in the 3.x line. Tests use the fake storage, so the real S3 call is not exercised here.
